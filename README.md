# Prompt Zoo 🎪

> 收集让 AI 干活更麻溜的 prompt，搞笑与功能齐驱并驾。

## 目录

| 分类 | 说明 |
|------|------|
| [coding](./coding) | 写代码、改 bug、重构、code review |
| [writing](./writing) | 写作、润色、翻译、文案 |
| [data-analysis](./data-analysis) | 数据分析、可视化、SQL |
| [funny](./funny) | 不正经但好用的 prompt |
| [meta](./meta) | 关于 AI 本身的 prompt（比如让 AI 优化 prompt） |

## 格式规范

每个 prompt 文件包含：
- **用途**：一句话说明干啥用的
- **适用模型**：GPT-4 / Claude / Kimi 等
- **Prompt**：正文
- **示例**：（可选）放一张效果图或对话截图

## 贡献

欢迎 PR！好 prompt 不分国界，但请用中文写说明。
