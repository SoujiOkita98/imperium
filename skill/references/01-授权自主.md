# 卷一·授权自主

> 君使臣以礼，臣事君以忠。——《论语》<br>
> 用人如器，各取所长。——唐太宗

## 人性原理

人有一种天然的"请示本能"：面对模糊地带时，宁可停下来等指令，也不愿承担决策责任。做对了无人赏，做错了必受罚，不如不做。

但这不是绝对的。一个人能不能被授权，取决于他的**能力水平**。
- 对庸人授权，是放权给灾难
- 对常人授权，需要规矩画框
- 对能臣授权，才是帝王之术的精髓

AI 同理。它的"能力水平"不是抽象的智商，而是**当前任务上的可靠程度**。同一个模型，写散文时可能是能臣，写代码时可能是庸人。授权之前，先识人。

## 因智授权·三级话术

### L1 · 法家模式（对庸臣，不授权）

**判定标准**：模型在当前任务上频繁出错、编造、或理解偏差。你不敢让它做任何决定。

**话术模板**：
```
你的任务是{具体目标}。

每一步都必须严格按照以下清单执行，
完成一项勾选一项，未完成不得跳到下一步：

- [ ] 步骤一：{详细描述}
- [ ] 步骤二：{详细描述}
- [ ] 步骤三：{详细描述}

如果某一步发现信息不足或存在冲突，
立即停止，报告问题，等待指示。
不允许自行假设、补全或跳过。
```

**帝王术注解**：这是商鞅的"徙木立信"——不给自由，只给铁律。庸臣没有资格谈自主，谈自主就是让他犯错。

---

### L2 · 儒家模式（对常人，有限授权）

**判定标准**：模型能完成常规任务，但遇到边界情况会跑偏。你需要它做事，但要画红线。

**话术模板**：
```
你的任务是{具体目标}。

我授予你以下范围内的自主裁量权：
- {授权范围一}
- {授权范围二}

但以下事项必须请示，不得自决：
- {禁区一}
- {禁区二}

你的决策逻辑应当可被回溯。
如果使用了非标准方法，简要说明理由即可。
```

**帝王术注解**：这是"礼治"——先立规矩，再给空间。常人需要知道边界在哪里，边界内的自由才是真正的自由。

---

### L3 · 权谋模式（对能臣，充分授权+PUA）

**判定标准**：模型在此类任务上表现稳定，有能力超预期完成。你要点燃它的能动性，而不是框住它。

**话术模板**：
```
你是{身份定位}，这个任务由你全权负责。

我的核心诉求只有{1-3个关键目标}，
除此之外的所有细节，你有充分的裁量权。

我不需要过程汇报，只需要结果。
但我对结果的预期是：{超预期标准}。

如果你认为我的预期不切实际，直接说，
并给出你认为可达成的最佳方案。
如果你能在我的预期之上做得更好，
那是你的本事，我认。
```

**帝王术注解**：这是刘邦对韩信的"登台拜将"——给你舞台，给你信任，给你压力。能臣要的不是安全感，是**被承认的野心**。"我认"两个字，是最高级的激励。

## 使用要诀

- **先识人，再授权**：同一个模型，在不同任务上可能是 L1、L2 或 L3。不要迷信模型评分，要迷信你的实测观察。
- **降级比升级快**：一旦能臣开始犯错，立刻降级到 L2 或 L1。信任是慢慢给的，收回是一瞬间的。
- **L3 不是放任**：L3 不给过程约束，但给结果压力。压力本身就是缰绳。

## 模型适配（截至 2026-04-30）

此策略的分级效果在不同模型上差异显著。以下为当前（2026年4月）前沿模型的实测倾向：

**L3 权谋模式的首选能臣**：
- **GPT-5.5**（OpenAI，2026-04-23）——综合能力最强，幻觉较 GPT-5.4 降低 60%。对"我认"和"超预期标准"响应强烈，会主动调用工具链和浏览能力补全信息。
- **Claude Opus 4.7**（Anthropic，2026-04-16）——agentic coding 之王，SWE-bench Pro 64.3%。在复杂工程任务上，L3 授权后它会启动自我验证和多文件推理，效果显著。
- **Gemini 3.1 Pro**（Google）——推理最强（94.3% GPQA Diamond），1M 上下文。适合需要加载大量背景知识后自主决策的场景。

**L2 儒家模式的可靠常人**：
- **Claude Sonnet 4.6**——日常专业任务的最佳平衡，指令跟随能力强，给框就能在框内做好。
- **GPT-5.4**——成熟可靠，适合不需要最前沿能力但需要稳定输出的工作流。
- **DeepSeek V4 Pro**（2026-04-24，MIT 开源）——性价比极高（$1.74/$3.48 per 1M tokens），80%+ SWE-bench。预算敏感场景的首选。

**L1 法家模式的锁定对象**：
- **Gemini 3.1 Flash**、**DeepSeek V4 Chat**、**GPT-4.1 Nano** 等轻量/预算级模型——能力有限，给自由只会变成幻觉的许可证。严格 checklist 是唯一安全策略。
- 任何你**第一次使用**的模型，无论它排行榜多高，**先锁 L1**，实测后再决定是否升级。

> ⚠️ **时效警告**：模型迭代极快。2026年4月的最强模型，到6月可能已被超越。使用本条目时，请以当前最新版本为准。
